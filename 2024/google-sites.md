## Note:  
Jika ingin membuat website melalui pemrograman (baris kode) diperlukan editor kode seperti Visual Studio Code, Sublime, dan CodePen.  

Template bisa didapat melalui Colorlib dan ThemeWagon, bisa juga menyalin kode yang tersedia pada halaman CopyPaste.  

Selanjutnya hosting dan deploy pada Github Pages dengan tutorial dari YouTube.
